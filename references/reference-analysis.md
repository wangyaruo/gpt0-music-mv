## 最重要的风格特征

1. **歌词驱动游戏动作。** 装备、关卡、NPC、战斗、地图和宝箱都有叙事用途，画面不是同一静图平移三分钟。
2. **人物与 UI 是连续系统。** 小角色发型和衣服、左上心形生命、金币、右上关卡名保持可识别。
3. **一句歌词是一段对白。** 深蓝色框、亮描边、小头像、白字、逐字出现和右下继续三角构成稳定阅读区。
4. **时间与关系共同推进。** 白昼、黄昏、逆光、月夜逐步变化，副歌的相似歌词获得新的视觉状态。
5. **有限动画制造游戏感。** 行走循环、跳跃抛物线、旋转金币、音乐弹体、爱心和烟花足以构成动感。
6. **像素与显示器外壳分层。** 场景是清晰像素，外层有暗角、扫描线、轻微倾斜/弯曲边缘；低码率压缩痕迹不应当作必须复刻的审美。

## 从参考提取，避免固化偶然细节

- 保留：歌词到机制的映射、固定角色、持续 HUD、对白字幕、关卡推进、副歌变奏。
- 可替换：歌曲、角色数量、情侣主题、热带海滩、关卡数、时长、标题与署名。
- 工具未确认：原片可能使用多个绘图/动画/剪辑工具；仅凭成片无法确定作者的软件、模型或提示词。
- 仓库示例是原创程序化像素风格原型，不是原视频的逐像素重建，不使用原片画面、原曲或原歌词作为发布素材。
